<p>Let's say you were working on an update but needed to push some partial code in a fix or another update. To do it, you can quickly call the interactive add feature of git to select the portions of code you want to add using the following:</p><pre><code class="language-shell">git add -p
</code></pre><p>This is also helpful if you want to know what you are adding.</p><p></p><!--kg-card-begin: html--><a href="https://github.com/k88hudson/git-flight-rules?ref=git.wtf#i-want-to-add-changes-in-one-file-to-two-different-commits" target="_blank" rel="noopener noreferrer" class="git-article-source">
